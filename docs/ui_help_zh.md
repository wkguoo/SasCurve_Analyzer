# 界面提示与帮助

把鼠标停在按钮、输入框、下拉框或分页标签上，可以查看用途、操作方法和操作后的结果。输入框选中后按 **F1**，也能查看同一说明；按 **Esc** 关闭帮助。

下拉框展开后，每个固定选项都有自己的说明。选中选项后，框上的提示同时解释当前选项。曲线名称相同时，可以在曲线列表或记录来源的提示中核对编号和原始文件位置。

首次使用可按以下顺序操作：

1. 在“数据导入”中选择已完成强度校准的曲线文件。核对横坐标列、强度列及单位，查看预览，再导入。
2. 在左侧选择一条曲线，在“数据检查”中查看缺失值、负强度和重复点等问题。
3. 打开“曲线工作台”，选择显示方式；下拉选项会解释图中坐标是怎样换算的。
4. 选择分析方法并核对横坐标范围，再运行分析。手动分析范围使用当前曲线的单位；全自动批量分析使用倒数埃（Å⁻¹），提示会提醒两者区别。
5. 用绘图页保存图片，或在“项目与输出”中导出表格。项目菜单可以保存曲线、结果和操作记录，以便下次继续。

曲线横坐标通常写作 **q**，较小的数值通常对应较大的结构尺度；强度是曲线纵坐标。测量误差表示强度可能上下浮动的大小，图上用数据点旁的上下短线表示。涉及假定形状、估计测量范围外的强度等方法时，请核对各结果中的条件和注意事项。

当前尚未启用的独立距离分布、相关函数入口，以及图像正式记录入口，会直接说明不可用原因和可用的相关入口。部分设置目前只保存偏好，提示会说明其实际作用。

## 维护说明

`app/ui/help_texts.py` 集中保存控件、动作、静态下拉选项、分页和表头说明。主窗口构建后调用 `install_ui_help(self)`；帮助只处理该窗口及其子对话框。新增控件应加入所属类和属性的说明，或通过稳定的 `objectName` 对应说明；同一动作更改可见文字时也需同步动作映射。

保持每条提示具体、简短：先说明用途，再说明怎么输入或选择，最后说明结果。优先用“曲线横坐标”“强度”“保存表格”等直接表达。需要方法名称、文件格式或单位时，就近解释其实际含义。保留对象编号和来源位置，保留方法条件；帮助更新不应改变数据、输入值或当前选择。

`tests/test_ui_help.py` 检查实际创建的控件及静态选项覆盖，并验证新弹窗、F1、窗口销毁后的事件、动态对象来源信息和帮助刷新期间的状态保持。原生系统文件选择器的显示由操作系统管理；应用内文件选择器的导航和确认控件已覆盖。
